## 🚀 Featured Projects

**[Socratic Tutor](https://github.com/chamathka-00/socratic-tutor)**
A retrieval-augmented (RAG) tutoring agent that diagnoses the misconception behind a student's wrong answer and guides them with Socratic questions instead of giving the answer. Built on Azure AI Foundry with vector + semantic search (Azure AI Search) and a Chainlit chat interface.

**[Multi-Tool AI Agent API](https://github.com/chamathka-00/multi-tool-ai-agent-api)**
A FastAPI service wrapping a LangChain agent (Groq Llama 3.3 70B) that autonomously selects and calls tools to answer natural-language queries, with typed Pydantic contracts, structured error handling, and conversation memory.

**[AWS Data Pipeline: Telecom Customer Churn](https://github.com/chamathka-00/AWS-Data-Pipeline-Customer-Churn)**
An automated, cloud-native data engineering pipeline on AWS (S3, Glue, Redshift, Airflow, Athena) that processes telecom data into a star-schema warehouse for BI reporting.

**[Soil Suitability Analysis](https://github.com/isumakm/Weather-Prediction-and-Crop-Recommendation-System-/tree/Soil-Suitability-Analysis)**
An end-to-end geospatial ML pipeline turning multi-layer GeoTIFF soil rasters into interpretable soil-management zones for Sri Lanka's Western Province, using clustering, SHAP, Moran's I, and a Leaflet.js interactive map.

**[Customer Churn Prediction](https://github.com/chamathka-00/Telco-Customer-Churn-Prediction)**
End-to-end machine learning on the IBM Telco dataset: feature engineering, SMOTE for class imbalance, GridSearchCV-tuned models (ROC-AUC 0.82), and responsible-AI checks.
